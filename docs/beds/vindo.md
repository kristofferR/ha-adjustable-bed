### Packet Format

The Linak control word is a one-byte opcode followed by a zero byte. The
position characteristics use the Vindö parser for raw readings. See the
[Linak guide](linak.md) for the other app profiles that share the control word.

### Write Mode

Writes use the control characteristic with response. The controller validates
the GATT roles and subscribes to legs, then back, before enabling commands.
The subscriptions accept notification or indication properties.

## Detection / Setup

Choose **Vindö (Carpe Diem Beds)** for a bed that works with the Vindö app.
Automatic discovery suggests it when the advertisement has both the control
service and a matching name, regardless of case. The shared service retains
the generic Linak receiver suggestion. You can also select Vindö manually.
When setup reaches a receiver, it checks the required GATT roles and rejects an
observed mismatch. Setup can continue while the receiver is offline.

To identify a connected bed, enable and press the **Identify Vindö bed**
diagnostic button. Home Assistant blinks that bed's light twice and sends OFF
before releasing the command.

Use **Linak: move two motors together** with the back and legs axes to
set a duration for combined movement, up to the movement deadline below. The
four combined-movement buttons send shorter pulses.

### Memory

Move the bed to the desired position, then use **Save to memory**. Saving
requires recent position reports for both axes and sends no BLE write. Recall
compares live readings with the saved readings and chooses a movement from the
table. The command stops as soon as both axes are in range or if either
current reading becomes unusable. Each bed address has its own saved positions.

## Position Feedback / Notifications

The first two bytes of each report are an unsigned little-endian count.
Additional bytes are ignored. Enable the raw position diagnostic sensors to
see these counts. The physical scale has yet to be verified, so Vindö provides
no position percentage or angle slider. Memories use counts saved from the same
bed. Verify travel and resting position on your hardware.

Movement cleanup sends STOP on the same initialized BLE link, including after
cancellation. A closed or replaced link invalidates its readings and command
ownership. Lighting and massage states have no hardware readback.
