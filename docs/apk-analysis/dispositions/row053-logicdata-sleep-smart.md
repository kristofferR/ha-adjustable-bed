## What changed

- New `sleep_smart` profile for `logicdata_app`: two-motor movement for both series, Middle Rail (`p2`) zero payloads on back/legs only, hold-only presets and memory 1 at a 200 ms refresh, one memory slot with a single save frame, factory reset, massage mode sensor and a massage-state refresh button.
- Startup follows the app: only both T3 subscriptions make the bed ready, also next to a selected T1/T2 write role, and then both ready-event query schedules run. The clock only answers `F2 F2 50`.
- Rename uses `01 FC 07` framing on T1 and T3, the app's edit-field alphabet and 20-character limit, and the retained T3/T1 name role for T2.
- New `logicdata_air_pump` bed type: inflate, deflate, firmness 30, pressure memory recall/save, stop, three-phase AT rename, and an air pressure sensor polled at the app's 800/500 ms cadence on a live link.
- `logicdata_rename` and `logicdata_hold_preset` now validate every target with its own rule before any write and release preflighted links on cancellation.
