## What changed

- Three explicit Keeson protocol variants, `simon_li`, `heal_every_night` and `okin_seating` (`beds/keeson_okin_apps.py`). The apps share the big-endian `E5 FE 16` frame but not their keys, release timing or features, and none of them identifies the device, so Auto never selects them.
- The apps' GATT choice (the first FFE9 of the last matching service in Java UUID order, write property required, Android's default write type) and their FFE4 subscriptions, whose replies stay diagnostic only.
- Simon Li: back, foot and lumbar covers, a Home button, memory 1/2 recall as held streams and Save memory as the app's 2.1 s hold. OKIN-Seating: back and foot covers and Home. Release sleeps 10 ms and writes the zero key.
- Heal Every Night: Healing 6/7/8 by motor count; head, foot, tilt and lumbar covers remapped by local Installation mode and Actuator direction selects; Flat, Zero G and memory A/B with the app's re-tap preset STOP; memory save; the massage page (timer select, head/foot/wave level numbers, +/- buttons, Off); the Healing 7/8 light. Release writes the zero key 100 ms later.
- New `okin_app_hold_control` action for any streamed control (0.1-60 s).
