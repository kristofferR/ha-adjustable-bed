# Row058: Restonic BT Remote app dispositions

The accepted Android app `com.keeson.restonicBT` 1.2.0 (3), "Restonic BT Remote", is one monolithic APK with one reachable BLE control protocol and two user-selected remote styles. The comparison accounts for **76 discovery items: 34 IMPLEMENTED, 10 ALREADY_IMPLEMENTED, 32 EXCLUDED**. Hardware is unverified (STATIC VERIFIED / HARDWARE UNVERIFIED).

The public contract is the [Restonic BT profiles](../../beds/keeson.md#restonic-bt-profiles). The frame is byte-identical to the Keeson Base builder, but the app's cadence, release, control sets and remote-style selection differ, and its `base-i4`/`base-i5` names are shared with other Keeson app families. The app is therefore two explicit Keeson profiles; Auto and every other profile keep their behavior.

## What changed

- New explicit Keeson protocol variants `restonic_a` and `restonic_b`, also offered in the setup wizard, matching the app's remote style setting. Auto keeps the Base profile for `base-i4`/`base-i5` names.
- Both write the Base E5 frame to FFE5/FFE9 only, without fallback, and mirror Android's default write type.
- Held controls refresh every 100 ms (10 x 100 ms per HA press by default); every control, including one-shot buttons, is released with one zero frame 100 ms later. The safety stop sends it at once.
- Remote A: head and foot covers, Flat, and a held Zero G. Remote B: adds a Back + Legs cover (combined `0x05`/`0x0A`), a one-shot Zero G, a light toggle button and a ZZZ button.
- No memory, massage, lounge, TV, anti-snore, tilt, lumbar or light entity, even with the massage option on.
- The generic `hold_control` action holds any control of the selected remote for 0.1-60 s, with the app's repeat and release.
- Discovery adds name-only `base-i4*`/`base-i5*` matchers, and any name starting with `base-i4` (dot optional) is detected as generic Keeson (Auto keeps Base). Any `base-i5` name is still offered as Cool Base (switch the bed type to Keeson and pick a Restonic profile).
- A Stop, cover stop or replacing command releases at once; the Back + Legs cover uses the `motor:*` lane so head or foot moves and stops preempt it.
- Switching remote B to A, or away from the profile, removes the Back + Legs cover, light and ZZZ buttons.
