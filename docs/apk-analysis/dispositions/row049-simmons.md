## What changed

- New explicit **SIMMONS app** bed type. Shared names and services never select it.
- The protocol variant carries the app's two independent choices: regular or inclined bed, and the packet format, either fixed or from the app's Bluetooth-name rule (`smartbed`, then `okin`; unmatched names use SmartBed).
- GATT roles follow the app: Nordic UART or FFE5/FFE9 plus FFE0/FFE4, last match wins, both required. OKIN frames are written with response, SmartBed frames without.
- All 40 command rows are byte-exact, including the inclined controls that always send SmartBed frames.
- Controls repeat every 300 ms and release with two STOPs at +100/+400 ms. Save Custom Mode holds the recall frame for 5.5 s. Preset, recall, light and inclined buttons are app taps (one frame, then the release STOPs). The generic `hold_control` action covers longer holds.
- Clock sync and the alarm page queries run during connection setup, before any command; `simmons_set_alarm` programs or disables either alarm with the app's mode, confirmation, conflict and weekday rules. Alarm 1/2 sensors show the parsed state.
- DewertOkin and actuator docs no longer imply this app uses the DewertOkin protocol.
