## Equivalence and safety boundaries

Shared helpers are reused only after the Hush packet/catalog comparison and artifact-vector checks. Exactly 37 complete product specifications equal the baseline catalog after expanding action memberships; 34 differ or are absent. Hush therefore owns its catalog and local policies. Exact repeated source aliases remain distinct in the fixture even when HA uses one equivalent action.

HA preserves command bytes, units, selection gates and relevant state effects. It deliberately replaces unsafe app singleton/queue/UI lifetime behavior with per-target connections, typed preflight, cancellation, same-side STOP and generation checks. A source bounds error or retained unmounted callback is not a bed feature. App-local color gesture throttling and 200ms callbacks become explicit HA service values, without emulating a Flutter widget. Safety exclusions do not authorize guessed packet substitutions.

Every code/test reference is in the corresponding JSON group. Report and acquisition bytes remain machine-local. Reproducers are not copied into the integration, and no acceptance label was rewritten.

## Validation limits

Focused catalog, packet, full notification-family, JSON, coordinator, paired-side, callback and UI tests accompany this change. The PR handoff records exact candidate hashes and actual check results. APK/static proof is not hardware confirmation. Physical motor mapping, firmware acknowledgement, device health values and native radio behavior remain unverified for real users after beta/release; no implementation is deferred for lack of maintainer hardware.
