# Row051: Adjustable Lite app dispositions

The accepted Android app `com.keeson.adjustablelite` 1.0.2 (5) is a complete four-member Google Play split set with one reachable BLE control protocol and two remotes (KSBT01C and KSBT03C). The comparison accounts for **91 discovery items: 50 IMPLEMENTED, 9 ALREADY_IMPLEMENTED, 32 EXCLUDED**. Rows overlap evidence coverage and are not distinct physical features. Hardware is unverified (STATIC VERIFIED / HARDWARE UNVERIFIED).

The public contract is the [Adjustable Lite profile](../../beds/keeson.md#adjustable-lite-profile). Every frame already existed in the generic KSBT profile, but this app labels memory, times movement and reports state differently, and the `KSBT03C` name is shared with Ergomotion Sync and Sleep Harmony. The app is therefore an explicit Keeson profile; Auto and every other profile keep their behavior.

## What changed

- New explicit Keeson protocol variant `adjustable_lite`, also offered in the setup wizard. Auto keeps the generic KSBT profile for `KSBT01C`/`KSBT03C` names.
- The device name chooses the remote: the case-sensitive token `KSBT03C` selects the KSBT03C remote, anything else the KSBT01C remote.
- Memory slots 1-3 follow the shipped MI/MII/MIII labels (`0x10000`, `0x2000`, `0x4000`); lounge and TV are not exposed.
- Movement repeats every 300 ms and release sends nothing. Writes target only `6e400002` and mirror Android's default write type.
- Only head/back and leg/foot covers. Anti-snore, head/leg massage steps and the massage timer button appear for the KSBT03C remote, without the massage opt-in.
- The `00 B0` status query runs every 500 ms on a live connection. Notifications publish a **Light** binary sensor and, on KSBT03C, a **Massage timer** sensor; both clear at disconnect.
- Discovery adds name-only `KSBT01C*`/`KSBT03C*` matchers, and names containing either identity anywhere route to the six-byte KSBT frames.
- Changing an entry's profile removes covers, buttons and state entities that the new profile does not expose.
