## What changed

- New explicit **Adjustable bed (Lumbar) app** bed type (`adjustable_lumbar`). Shared names and services never select it.
- The app's table rule: lowercase `okin` prefix selects `36_33_04a` (OKIN service, with response); `star` selects `25_42_02` (Nordic UART, without response), or `35_22_01` when the manufacturer reply is exactly `STAR`. Other names are refused; fixed `okin`/`star` variants cover a name HA cannot see.
- All 126 command rows are dispositioned; every distinct reachable frame is byte-exact and tested.
- Held controls refresh every 100 ms and release with STOP at 0 and +300 ms. Buttons are app taps; saves hold the Flat+preset frame for the app's 6 s report time; the generic `hold_control` action covers longer holds with all-target preflight.
- The voice-only massage-on frame and the raw massage query are exposed as buttons. Replies are kept raw, as no shipped parser consumes them.
- Connection requires the app's roles and Device Information service; one raw manufacturer read replaces the generic Device Information pass.
- The raw Bluetooth name persistence and two-address variant guard that SIMMONS used are generalized to both name-rule profiles.
