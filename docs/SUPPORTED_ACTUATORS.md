# Brand Lookup

Find the brand on your bed or base to see which bed family it uses, then follow
the link to that family's guide. The
[Supported Beds table](../README.md#supported-beds) lists every app and remote.

A brand can appear in more than one family, because the same brand has sold
beds with different controllers. Lucid L600, for example, has been sold with
two different Okin controllers. The brand alone does not decide the family: add
the bed, let Home Assistant discover it, and pick the app or remote you use. If
the result is wrong, open the entry's three-dots menu under **Settings >
Devices & services > Adjustable Bed** and choose **Reconfigure**.

## Identifying Your Bed by Its Bluetooth Name

The bed's Bluetooth name, shown in **Pick any Bluetooth device** and in
diagnostics, often points to its family:

- A name beginning with accepted `QMS-IQ`, `QMS-I06`, `QMS-LQ`, `QMS-L04`, `QMS-JQ-D`, `QMS4`, `QMS-NQ`, `QMS3`, `QMS-MQ`, `QMS2`, `My QMS2`, `SealyMF`, or exact `S4-Y-<digits>-<id>` → [Solace](beds/ff_frame.md#solace-name-routes)
- `HHC*` → MotoSleep
- `DPG*` or `Desk*` → Linak
- `Mouselet*` → Kaidi
- `Nectar*` → Nectar
- `Okimat*`, `Okin RF*` → Okin; setup asks which remote
- `OKIN-Receiver`, `OKIN - Receiver` → Okin; setup asks which remote
- `Leggett*`, `L&P*`, `Adjustable Base*` → Leggett & Platt
- `Ergomotion*` or `Ergo*` → Keeson/Ergomotion
- `KSBT03*` or `KSBT04*` → Keeson KSBT (includes some Ergomotion Sync beds such as Rio 6.0)
- `Jiecang*`, `JC-*`, or `Glide*` → Jiecang
- `Dewert*`, `A H Beard*`, `Hankook*` → DewertOkin
- `Serta*` or `Motion Perfect*` → Serta
- `Octo*` → Octo (Standard variant)
- `iFlex*` → Mattress Firm 900
- `OKIN-*` → Okin, often [Okin CST](beds/okin-nframe.md#okin-cst) or the [RF ECO BT stair lift](beds/okin-nframe.md#rf-eco-bt-stair-lift); setup asks which
- `Malouf*`, `Structures*` → Malouf
- `Smart bed *` → [Sleep Number](beds/sleep_number.md) (Climate 360 / FlexFit, Fuzion)
- A name that looks like a Bluetooth address, such as `64:DB:A0:07:DD:02` → possibly [Sleep Number](beds/sleep_number.md) (i8 / 360 FlexFit 2, BAM/MCR)
- `Sleepy*` or `MFRM*` → [Sleepy's Elite](beds/sleepys.md#home-assistant-setup); setup asks for the app or the receiver the bed advertises
- `SLEEPSTAR*` → [SleepSpa S9000AI](beds/sleepstar.md) (`SLEEPBT*` is a different, unsupported device)
- `VMAT*` → Vibradorm
- `SUTA-*` → [SUTA Smart Home](beds/suta.md)
- `AHF*` → TiMOTION AHF
- `Limoss*`, `Stawett*` → Limoss
- `OKIN-BLE*` → [Malouf / Lucid](beds/malouf.md) or another Okin family; setup asks which
- `Rize*` → Often [DewertOkin](beds/okin-nframe.md#dewertokin), but `Mouselet*` devices are [Kaidi](beds/kaidi.md)
- `Simmons*`, `Glory*`, `Symphony*` → See [DewertOkin](beds/okin-nframe.md#dewertokin); beds you control with the SIMMONS app → [SIMMONS app](beds/okin-nframe.md#simmons)
- `Star35*` → [Okin CB35](beds/okin-5a.md#sealy-posturematic-cb35) (Sealy Posturematic)
- `SILVERmotion*` → [LOGICDATA](beds/logicdata.md)

If the name does not help, or Home Assistant does not see the bed at all, check
the bed with [nRF Connect](https://www.nordicsemi.com/Products/Development-tools/nRF-Connect-for-mobile)
on your phone, then [capture a support bundle](GETTING_HELP.md#generating-a-support-bundle)
and [request bed support](https://github.com/kristofferR/ha-adjustable-bed/issues/new?template=new-bed-support.yml).

## Not Supported

### TOPSKY TV MOUNT

The **TOPSKY TV MOUNT** app (version 1.2.6) controls a TV mount, not a bed, so
it is outside this integration. Other Okin apps and beds are not affected.

### SmartSofa

The **SmartSofa** app (version 1.1.3) controls sofas, recliners and their
accessories, not beds, so it is outside this integration.

### WiFi and Cloud-Based Beds

**[Won't be supported, read reasons here](https://github.com/kristofferR/ha-adjustable-bed/issues/167).** This is a Bluetooth-only integration. WiFi and cloud beds require fundamentally different architecture and would be better served by a separate integration.

Beds that won't be supported:
- **Sleeptracker-AI cloud features**: accounts, sleep data, Wi-Fi setup and other cloud services of Tempur-Pedic Ergo, BeautyRest SmartMotion and Serta Motion bases. The Tempur Sleeptracker-AI processor's direct Bluetooth controls on TEMPUR-Ergo ProSmart / ProSmart Air and ActiveBreeze beds are supported; see the [Sleeptracker processor guide](beds/sleeptracker.md)
- **Logicdata eLift / desk controllers**: use local network control, not Bluetooth
- **ErgoWifi**: uses a cloud service
- **Layla Adjustable Base Remote** (version 1.1.5): controls the bed over Wi-Fi
  or a cloud service. Other Layla controllers may use Bluetooth.

LOGICDATA MOTIONrelax BLE app layouts have an explicit [LOGICDATA app profile](beds/jiecang.md#motionrelax-phone-and-tablet) over the Jiecang codec; the Sleep Smart Air Mattress app has its own [bed profile](beds/jiecang.md#sleep-smart-air-mattress-bed) and [pump type](beds/logicdata-sleep-smart.md). Existing legacy [Jiecang](beds/jiecang.md#legacy-route) entries retain their original protocol.

If you have one of these beds, consider running [smartbed-mqtt](https://github.com/richardhopton/smartbed-mqtt) as an add-on or make a separate integration for WiFi/Cloud adjustable beds.

### Other Integrations

These beds have their own dedicated integrations:
- **Eight Sleep**: use the [Eight Sleep](https://github.com/lukas-clarke/eight_sleep) integration
